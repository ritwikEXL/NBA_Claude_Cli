CareIntel — Next Best Action
for Medicare Stars

CareIntel helps Medicare Advantage plan managers close HEDIS/Stars measure gaps faster by combining AI-driven opportunity analysis, member segmentation, campaign design, and multi-channel outreach — all in a single guided workflow. The platform turns raw member gap data into a prioritized outreach plan with projected CMS bonus impact in minutes.

System Design

Architecture

CareIntel is a three-layer system: a data layer (SQLite + CSV inputs), a backend layer (FastAPI + AI agent loop), and a frontend layer (vanilla JS dashboard). All communication is REST over localhost — no build step needed.

Data Contracts

Input Files (read-only)

All source data lives in input/. These are treated as read-only — agents never modify them. You can replace them with your own CSVs or a SQLite .db file via the "Connect Data Source" upload in the dashboard.

FileKey ColumnsDescription
fact_member_gap.csv member_gap_key, gap_status, nba_propensity_score, days_open Core fact table — one row per member × measure × year. The engine that drives every decision.
dim_member.csv member_key, age_band, digital_literacy_segment, language_preference Member demographics used for cohort segmentation and channel selection.
dim_member_channel_pref.csv member_key, sms_allowed, email_allowed, preferred_channel, do_not_contact_flag Channel permissions and DNC flags. Always respected by the outreach agent.
dim_measure.csv measure_key, measure_code, star_weight, hedis_domain HEDIS/Stars measure definitions including Star weight used in all ROI calculations.
dim_member_channel_pref.csv plan_key, plan_name, star_rating_current, star_rating_target, plan_pmpm_monthly Plan-level metadata. PMPM drives the CMS bonus formula.
Uploading your own data
Column names must match exactly. The auto-detector fingerprints each CSV by its headers — if it finds member_gap_key + gap_status + nba_propensity_score, it maps the file to fact_member_gap. You can upload a mix of files or a single .db file containing multiple tables.

Dashboard

Feature Map

📊
Financial Opportunity Analysis
Per-card breakdown of every measure × plan combination: compliance rate vs. national benchmark, open gaps, estimated CMS bonus, projected Stars improvement, outreach cost, and ROI. Cards show all three outreach tiers (Tier-1 digital, Tier-2 call, Tier-3 field).
🎛️
Budget Optimizer
Drag a budget slider to see which campaigns get funded first. Uses a greedy ROI-ranked allocation algorithm with per-plan Stars caps (0.30★ portfolio max). Shows projected CMS bonus vs. the theoretical maximum for your plan portfolio.
🤖
AI Opportunity Analysis
"Run AI Analysis" triggers Claude to scan all gaps, calculate financial impact, rank opportunities by ROI, and write plain-English reasoning for each. Results appear in a live progress panel with confidence level (HIGH/MEDIUM/LOW) and projected CMS bonus.
🧭
4-Phase NBA Wizard
Guided session: (1) pick an opportunity, (2) approve cohorts, (3) confirm campaign design, (4) generate outreach plan. Each phase shows an AI agent status, allows overrides, and requires explicit confirmation before proceeding. Each confirmation also silently triggers a background AI loop for richer DB writes.
📂
Data Source Upload
Drag-and-drop any CSV or SQLite .db file. The API auto-detects which table it maps to by reading column headers, replaces the existing data, then immediately kicks off Claude AI analysis on the new dataset. Results are surfaced in the upload modal itself.
💬
WhatsApp Conversations
Full two-way WhatsApp conversation state machine via Twilio. Outbound message → member replies → appointment booking → follow-up check → gap closure. NLP parses YES/NO/DATE replies. A simulator lets you test the flow without a real WhatsApp number.
📧
Email Outreach
AI-generated personalized email previews per member (via Claude), sent through SendGrid. Preview renders in the outreach panel before sending. Batch send-all supported for an entire NBA run.
🏆
Campaign Evaluation
Post-campaign scoring: actual closure rate vs. expected, Stars impact actual vs. projected, performance status (EXCEEDING/ON_TRACK/BELOW). Evaluation schedule tracks 30/60/90-day windows. Member-level evaluation flags who needs a follow-up action.
AI Engine

The 4-Agent Loop

Claude operates via a tool-use agentic loop (while finish_reason == "tool_calls"). It has access to 7 database tools and cycles through four distinct agent personas — each one a different system prompt that shapes Claude's reasoning for that phase.

Phase 1
Opportunity Selection
Opportunity Agent
Queries all measure × plan gaps. Calls calculate_financial_impact on the top 5 by star_weight × open_gaps. Ranks by ROI. Writes analysis rows.
Writes → claude_opportunity_analysis · fact_nba_trace
Phase 2
Cohort Design
Segmentation Agent
Queries member-level data for the selected opportunity. Designs 2-4 cohorts by propensity, digital literacy, channel availability, language, and days open.
Writes → fact_nba_claude_decision · fact_nba_trace
Phase 3
Campaign Design
Campaign Agent
Designs channel strategy (SMS/email/call), frequency plan (e.g., 2 SMS in 14 days → call day 21), and incentive tier ($0/$15/$25/$50). Respects DNC flags.
Writes → fact_nba_claude_decision · dim_nba_campaign
Phase 4
Outreach Plan
Outreach Agent
Generates per-contact outreach schedule. Summarizes total contacts by channel and expected Stars lift. Writes final audit trace.
Writes → fact_nba_outreach_plan · fact_nba_trace

The 7 Database Tools

ToolWhat it does
query_opportunitiesReturns all measure × plan combos with open gap counts, compliance rates, and plan metadata. Filterable by measure or plan.
query_membersReturns member-level demographics, channel preferences, propensity scores for a specific measure × plan. Used for segmentation.
calculate_financial_impactPure calculation — CMS bonus, Stars delta, ROI, outreach cost. Applies per-campaign cap (star_weight × 0.15) and portfolio cap (0.30★).
write_opportunity_analysisPersists Claude's ranked analysis to claude_opportunity_analysis table.
write_session_decisionWrites or updates NBA decision rows for a cohort of members in fact_nba_claude_decision.
write_traceAppends an audit trace row — agent name, step label, input/output summaries, affected member count.
get_historical_performanceReads past campaign evaluations — actual vs. expected closure rates — so Claude can calibrate its recommendations against prior results.

How to Use It

Demo Flow — What to Walk a Stakeholder Through

Step 1 — Review opportunities

Open the Opportunities tab. You'll see financial analysis cards for every measure × plan combination. Each card shows: current compliance rate vs. the national benchmark, number of open gaps, projected CMS bonus if all gaps close, and outreach cost by tier. The Budget Optimizer slider lets you see exactly which campaigns get funded at a given spend level.

Step 2 — Run AI analysis

Click Run AI Analysis in the purple panel. Claude will scan all 35 measure × plan combinations, calculate financial impact on the top 5, and surface its ranked recommendations with ROI rationale in about 30–60 seconds. Results persist to the database so they survive a page refresh.

Step 3 — Connect your own data (optional)

Click Connect Data Source in the teal banner. Drop in your own fact_member_gap.csv (and optionally your dimension files). The system auto-detects the table, ingests the data, and immediately re-runs the AI analysis on it. No schema changes needed — just match the column names.

Step 4 — Run a session

Switch to the Run Session tab. Either click Select This Opportunity from an opportunity card, or choose one from the dropdown. The wizard walks through 4 phases. At each phase, an AI agent status panel shows what's happening in the background, and you confirm before proceeding. You can tweak channels, incentives, and cadence at Phase 3 (Campaign Design) before confirming.

Step 5 — Preview and send

At Phase 4 (Outreach Plan), click Preview Messages to see Claude-generated, personalized outreach text for each member. Then click Send All to dispatch via WhatsApp or email. A real Twilio webhook handles replies.

Step 6 — Track outcomes

The Evaluation tab shows post-campaign performance — actual vs. expected closure rates, Stars impact, and which members still need follow-up. The POST /evaluate/run-scheduled endpoint can be called on a cron to auto-score at 30/60/90-day windows.

For a new product manager on day one
The fastest path to a live demo: run setup_database.py + generate_synthetic_data.py, start both servers, open the dashboard, click "Run AI Analysis". Within 60 seconds you'll have Claude's ranked opportunity analysis with real reasoning. No Twilio or SendGrid keys needed for this path.
Bring Your Own Data

Uploading External Data

The "Connect Data Source" modal in the Opportunities tab accepts any combination of CSV files or a single SQLite .db file. The system handles the mapping automatically.

CSV upload rules

  • UTF-8 encoding (BOM is handled automatically)
  • Column names must match the key columns listed in the Input Files table above — order doesn't matter
  • Extra columns are accepted and ignored
  • Uploading a file replaces the existing table entirely — it's not an append
  • You can upload multiple files at once; each is auto-detected independently

SQLite .db upload rules

  • Table names must match exactly: fact_member_gap, dim_member, etc.
  • Only the five core tables are copied — other tables in your DB are ignored
  • Column names within each table still need to match the schema

What happens after upload

The API ingests the files, then automatically calls run_opportunity_analysis() — Claude scans the new data, calculates financial impact, and ranks opportunities. The modal shows the top 3 results inline. Clicking "View Updated Opportunities" refreshes the full dashboard with your data.
